# ScanWhile rejects minimumCount: 0 — forces an Optional wrap with a different tree shape

- Surfaced by: the TOML 1.0 port (E2ESamples/Toml). The literal-string body in TOML is `*literal-char` — zero or more chars between the apostrophes. The natural InductorParser shape is `ScanWhile(literalChar, minimumCount: 0)`. That throws at construction with `minimumCount must be at least 1` (ScanWhileRule.cs line 31). The only way around it is `Optional(ScanWhile(literalChar))`, which produces a different tree shape: when the body is empty (input `''`), the Optional has no Symbol child, so the consumer has to special-case `stringNode.Children.Count == 0` instead of just calling `Children[0].ToString()`. See `TomlParser.ExtractLiteralStringBody` for the workaround.
- Why it hurts: ScanWhile is the perf-tuned "scan a contiguous run of these chars" primitive, and grammars where the run can legitimately be empty (string bodies, optional-text fields, anything that may be absent) are common. Forcing the user to use `ZeroOrMore(OneOf(set))` instead loses the perf win (one Symbol per char vs. one leaf over the whole run). Forcing `Optional(ScanWhile(...))` is a separate workaround that reshapes the tree and doesn't compose cleanly with the rest of the body grammar.
- Two reasonable fixes:
    - Drop the constraint. `minimumCount: 0` produces an empty leaf when no chars match. The leaf's source range is `[start, start)` (zero width) at the current position. ScanWhileRule.cs already returns "match success with N consumed" so the N==0 case is a one-line change at the validation site. Open question: does an always-succeeding zero-width match break any of the lookahead-skip / FirstConsumedTokens machinery? RuleStartRequirements would need to advertise `Advance.Sometimes` for this rule when min == 0, same as Optional(ScanWhile(...)) does today.
    - Add a sibling factory `ScanZeroOrMore(TokenSet set)` that's explicit about the always-succeeds semantics. Slightly more typing for the caller but no risk of breaking the existing min-1 contract for callers that depend on it.
- Done when: a TOML literal-string body grammar reads `ScanWhile(literalChar, minimumCount: 0)` and produces a single named leaf Symbol whose ToString is the empty string for input `''`. The TomlParser.ExtractLiteralStringBody workaround can be deleted.

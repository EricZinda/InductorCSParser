    - Current state: under `INDUCTOR_DEFAULT_ENGINE=statemachine dotnet test` 35 of the 77 failures are existing recursive-engine trace tests where the assertion is a byte-for-byte string compare against the recursive engine's trace output. Two reasonable paths. That is much bigger, slows down the SM trace path, and is mostly bookkeeping the SM was deliberately built to skip. (a) is the right call; the trace contract that lives in the recursive engine's per-call output is a property of *that* engine, not a contract the SM should match.

- Generated-file round trips reproduce stale prose
    - A test that reconstructs generator input from a checked-in generated file, invokes the emitter, and compares the two files catches hand edits and emitter drift, but it can't validate the truth of comments emitted from a shared header template. If the template and generated file both make the same stale claim, the round trip passes.
    - Concrete instance: `UnicodeNormalization.Data.cs` and `UnicodeNormalizationDataTests.DataFileHeaderLines` both said the composition-pair dictionary is derived “at static init.” `UnicodeNormalization.cs` intentionally stores a `Lazy<Dictionary<long, int>>` and explains that construction is deferred until the first composition lookup to avoid partial-class field-initialization ordering.
    - Review generated prose against the consuming implementation independently. Structural tests can lock observable facts such as field shape or lazy state where practical, but the emitter equality check isn't an oracle for semantic documentation.

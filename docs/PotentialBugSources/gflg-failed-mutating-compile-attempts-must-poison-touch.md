- Failed mutating compile attempts must poison touched rules
    - Shape: a compile-time pass both validates a graph and mutates per-rule state as it walks. The pass reports all offenders at the end so users get one complete error list, but mutation happens before the pass knows whether the whole graph is valid. If a later node reports an offender, the entry point throws while earlier nodes keep their mutated state on an otherwise unsealed grammar.
    - Why it hurts: callers commonly catch a compile error, adjust the compile form or grammar setup, and retry. A failed compile that has already entered a mutating phase can't promise the grammar is still in a coherent pre-compile shape. If the failed attempt rewrote a sibling literal, set, cached rendering, or id, the retry parses a hybrid grammar: part original, part normalized for the form that just failed.
    - Concrete instance: `Rule.Compile(FormKC)` validated normalization by walking every child and calling each rule's `ValidateNormalization`. `LiteralRule` rewrote `_expected` immediately. `OneOf`-shaped rules rewrote `_set` immediately. `GraphemeRule` could rewrite `_expected` and the auto-rune id. A later Token containing the fi ligature (U+FB01) made Compile throw, but an earlier Literal containing the Kelvin sign (U+212A) had already become `"K"`. Retrying the same grammar with `Compile(null)` then rejected the original Kelvin sign even though null normalization should preserve it.
    - Fix shape: once `Compile` reaches the mutating phase, any exception poisons the touched rule graph. The original failure is still thrown unchanged. Any later `Compile` that reaches a poisoned root or child throws a deterministic "build a fresh grammar instance" error instead of continuing from partial state.
    - Audit hook: for every future compile-time pass, ask whether it can both mutate state and later fail. If yes, either make the pass atomic before mutation begins, or mark the touched nodes invalid on failure. Watch especially for cached render strings and side fields derived from the main mutation: changing `_set` without changing `_setRendered`, or changing a Token's `_expected` without changing its id, leaves a subtler hybrid state behind.

  - Reviewed source: `TokenSet.cs` header comment (the operator table and the "Set difference is the idiom a & ~b" claim), `operator &` + `MergeMultiRuneGraphemeIntersect`, `operator ~`, the rune+cluster representation split, and the consumers `OneOfRule` / `NoneOfRule` / `ScanWhileRule`.
  - Category checked: documented idiom vs. true set semantics on a MIXED minuend (a set carrying multi-rune grapheme members). `a & ~b` is presented as "a minus b" but is only true difference when `a` is rune-only. `~b` is rune-only by construction, so `a & ~b` intersects `a`'s cluster array with an empty one and silently drops every cluster `a` had. `Ascii.AnyWhitespace & ~Single(' ')` loses the CRLF cluster, so `OneOf(thatSet)` stops matching a "\r\n" token under the default Compile(FormC). For rune-only `a` it equals `a & ~b`, so existing grammars are unaffected. Updated the header comment to add `-` to the operator table, recommend `a - b` for difference, and demote `a & ~b` to the rune-only shorthand with the silent-drop caveat.

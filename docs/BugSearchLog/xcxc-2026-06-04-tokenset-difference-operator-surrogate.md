- 2026-06-04 TokenSet `-` (difference) operator surrogate sweep (focus: TokenSet operations / claims)

  - Directed sweep on TokenSet per request ("focus on TokenSet, its operations, its use in rules, its claims"), zeroing in on the brand-new `operator -` added the same day in 38c3fea. The earlier same-day sweep (2026-06-04-tokenset-operator-complement-comment-claims) differential-tested `|`/`&`/`~` but predates / doesn't list the `-` operator, so difference was uncovered.
  - Reviewed source: `TokenSet.cs` `operator -`, `MergeMultiRuneGraphemeDifference`, `operator ~` (the surrogate-stripping complement it reused), `operator &`, `EmitScalarInterval`, `Surrogates` / `SurrogateRange` / `Universe` constants, plus the difference tests added in 38c3fea.
  - Categories checked: set-algebra laws on the new operator (`X - Empty == X`, `X - X == Empty`), surrogate preservation through difference, parity with the documented "true set difference: every member of a that isn't a member of b" claim, and the cluster-vs-rune split.
  - Found + fixed: `operator -` computed its rune part as `new TokenSet(a._ranges) & ~new TokenSet(b._ranges)`. `~` complements over the scalar universe only (surrogates excluded by design), so intersecting `a` with `~b` strips every surrogate from `a` regardless of `b`. Result: any surrogate-bearing minuend is silently emptied of surrogates. `TokenSet.Surrogates - TokenSet.Empty` returned `[]` instead of `[U+D800-U+DFFF]`, breaking the basic `X - Empty == X` law and the operator's own "every member of a that isn't a member of b" promise. Surrogates are first-class set members (`TokenSet.Surrogates` / `SurrogateRange`, matchable under `Compile(null)`), so under an unnormalized compile a grammar that wrote `OneOf(TokenSet.Surrogates - excluded)` got a rule matching nothing. Replaced the `& ~` route with a direct surrogate-preserving interval subtraction (`SubtractRuneIntervals`) that complements `b` against `a`'s own intervals, the bounded universe the doc comment already promised. Added `Difference_keeps_minuend_surrogates_not_in_subtrahend` to `TokenSetTests.cs`. Full project green (7166 passed, 2 skipped).
  - Not bugs (verified): the cluster half (`MergeMultiRuneGraphemeDifference`) was already correct. The rune-only and cluster cases the 38c3fea tests cover are unchanged by the fix (rune-only minuends never hit the surrogate path, so `a - b == a & ~b` still holds there).

- 2026-06-03: Primer4.md "Security-Related Concerns" examples: a nonexistent TokenSet.Contains call and a NoneOf+AnyToken rule that consumes two tokens per iteration (follow-up to the Primer3 find, same session)
    - Trigger: after adding the missing Primer3Examples.cs, checked whether Primer4.md was also untested. It was (DocExamples had Primer1/Primer2 only). Read Primer4.md and ran every snippet against the live library in a scratch console.
    - Found and fixed two drifted snippets, both the "doc with no backing test" gap (`PotentialBugSources/aaaa-...`):
        - StripInvisibles (Unicode "Invisible characters" section) read `.Where(r => !Invisibles.Contains(r))` where `Invisibles` is a `TokenSet`. `TokenSet` has no `Contains`. The membership methods are `ContainsRune(int/char/Rune)` and `ContainsToken(...)`. The line doesn't compile. The real SecurityByDefaultTests version uses a `HashSet<int>` (so `.Contains(int)` there is HashSet.Contains, not TokenSet), which is why the gap never surfaced. Fix: `!Invisibles.ContainsRune(r)`.
        - safeUsername ("allowed"-rule username refusing invisibles) was `OneOrMore(And(NoneOf(Invisibles), AnyToken()))`. `NoneOf` already consumes one token, so `And(NoneOf, AnyToken)` consumes two per iteration. The documented `safeUsername.Parse("admin").Success == true` is actually false (5 tokens, odd, so the rule only accepts even-length input), and `"ad<ZWS>min"` returns false for the wrong reason. The doc's own comment ("the ZWS fails NoneOf(Invisibles)") describes `NoneOf(Invisibles)` as the per-character check, so the fix drops the bogus `And(..., AnyToken())`: `OneOrMore(NoneOf(Invisibles))`. Now admin=true, ad<ZWS>min=false, matching the doc.
    - Other Primer4 snippets verified clean as written: the ReDoS validator and the textbook `(a+)+` shape (both linear, reject pathological input cleanly), the FormKC compatibility-lookalike blocker (math-bold / fullwidth admin all match), the ASCII script-restriction username (rejects Cyrillic / math-bold / fullwidth under default FormC), and `Category(Format) & ~Single(0x200D)` (drops ZWJ, keeps ZWS).
    - New backing test file `src/InductorParser.Tests/DocExamples/Primer4Examples.cs` (7 tests) mirrors the corrected snippets and pins the documented behavior so Primer4 can't rot again. `dotnet test --filter FullyQualifiedName~Primer4Examples` => 7/7 pass.

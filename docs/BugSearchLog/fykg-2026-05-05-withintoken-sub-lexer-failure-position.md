    - Reviewed: `WithinTokenRule.cs`, `Lexer.cs` (sub-lexer constructor and `oneRunePerToken` mode), `Lexer.FastPaths.cs`, `EofRule.cs`, `PeekRule.cs`, `NotRule.cs`, `LateBoundRule.cs`, `AnyTokenRule.cs`, `AndRule.cs`, `OrRule.cs`, `BetweenInclusiveRule.cs`, `SourcePositionConverter.cs`, `GraphemeClusterIndex.cs`.
    - Categories: mid-grapheme-cluster failure positions reaching `outerLexer.RecordFailure`, position-unit lies in `ParseResult.Error*` / `Symbol.SourceRange`, sub-lexer-vs-outer-lexer coordinate mismatches, partial-output cleanup on inner-rule failure inside a one-rune-per-token sub-lexer.
    - Found and fixed: `WithinTokenRule`'s two failure paths recorded the sub-lexer's rune-scoped position (`subLexer.Position` directly, or `Math.Max(subLexer.DeepestFailure, subLexer.Position)`) on the OUTER lexer. The sub-lexer walks runes inside one outer cluster, so its position can sit between the runes of a multi-rune token (`é` decomposed, CRLF, Devanagari consonant + vowel sign, ZWJ emoji), which is mid-cluster from the outer view.
    - Observable for `WithinToken(OneOf(TokenSet.Ascii.Letters)).Compile(null)` parsing `"é"`: `ErrorCharIndex = 1` (mid-cluster), `ErrorTokenIndex = 1` (past-the-end since the input is exactly one cluster), and `ErrorMessage` reads `Parse failed at offset 1: unexpected '́'.` where the user typed `é` at offset 0 as one character.
    - Backlog p3kt has the write-up. The fix swaps both `RecordFailure` positions for `outerTransaction.StartPosition` (== `token.Offset`, the outer cluster's start), the same primitive every cluster-scoped rule already uses. Trace messages keep the inner rune-relative offset since they're labeled inner-token relative. Added two regression tests in `WithinTokenRuleTests` (one per failure path) asserting all four position units plus the bundled `ErrorPosition`.
    - Also added a "Mid-cluster failure positions reaching the outer parser" entry to `docs/PotentialBugSources/` noting that even correct char-unit rendering can be undermined by a mid-cluster position upstream.

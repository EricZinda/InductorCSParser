  - Found and FILED (backlog `abkn`, left unfixed per the batch-the-perf-fixes preference): `NormalizedPositionMap.TranslateViaLockstep` (and the FormKC/FormKD `TranslateViaPerGraphemeNormalize`) re-start their grapheme walk from `origPos=0; normPos=0` on every call, so each translate is O(offset). `Symbol.SourceRange` / `SourceText` call it twice per node whenever `ReferenceEquals(original, parseInput)` is false, i.e. when the caller's input wasn't already in the compile form (NFD / decomposed text under the default `Compile(FormC)`). A consumer reading a `SourceRange` per node across the tree is then O(N x L), quadratic in document size. Measured on a word-per-line grammar over decomposed `"é"` letters under FormC with `PreserveAllSymbols`, reading `SourceRange` on every node: 4000 lines ~14.7 s, 8000 lines ~56.0 s, size-doubling ratio 3.80x. Measurement was prototyped, ratio recorded, then deleted.

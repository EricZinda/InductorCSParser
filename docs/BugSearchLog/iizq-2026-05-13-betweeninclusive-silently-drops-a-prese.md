    - Found and fixed: `BetweenInclusiveRule.TryParseRule` loop body at lines 97-115 broke out on the zero-width-match guard *before* calling `outputSymbols.Add(nextSymbol)`. When Inner has `FlattenType.Preserve` and succeeds with zero width (e.g. `Not(X).Preserve()` when X fails, `Peek(X).Preserve()` when X succeeds, `Eof().Preserve()` at end of input, or any Preserve'd composite of zero-width children), Inner returns a real wrapper Symbol the parent is supposed to put in the tree. The break dropped the wrapper on the floor. `Tree.Find(inner)` returned null even though Inner's assertion held. Repro: `var guard = Not(Literal("Z")).As("guard").Preserve(); And(Literal("ab"), Optional(guard), Literal("X").Preserve()).Preserve().Parse("abX").Tree.Find(guard)` returned null; the same `guard` *without* the `Optional` wrapper reached the tree fine via the existing `SourceRange_on_Not_reports_zero_width_at_its_anchor` test. `AndRule.TryParseRule` (lines 32-35) added zero-width Preserve'd children unconditionally, which is why the bug was specific to BetweenInclusive shapes. The fix introduces a `bool zeroWidthMatch` local right after `ParseChild`, runs the existing non-Discarded Add line on every successful child, then gates only the break on the zero-width condition. count semantics are unchanged on every path: a zero-width inner still doesn't bump count (so `Exactly(n, zero-width)` still rejects "needed n matches but got n-1 zero-widths"); the only delta is that a Preserve'd zero-width inner's wrapper now reaches the parent's children list.
    - Considered the alternative shape of moving the `count++` before the break too (treating the zero-width match as one match for counting purposes). Rejected: that changes `Exactly(1, Not(X))` from fail-when-X-fails to succeed-when-X-fails, and the existing "Exit with whatever count we have. The AtLeast check below decides if that's enough" comment makes the no-count-on-zero-width semantics explicit. The minimal fix is to honor Inner's contract (add the returned wrapper) without changing what counts as a match.
